## Monday
// **MEADOWS ROW** — Use a landmine or T-bar attachment. Brace one hand on a bench, pull with an overhand grip driving the elbow up and back. Work up to a tough 8. Last set is a triple drop set (e.g. 90x8 → 75x6 → 60x6). First 2 sets stop at clean 8. RPE 10.
